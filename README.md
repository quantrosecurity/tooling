# tooling

Open-source tools from [Quantro Security](https://quantrosecurity.ai).

Each tool lives in its own top-level directory with its own README, and is built
to run straight from a checkout — no global install required.

## Tools

| Tool | What it is |
| --- | --- |
| [`vrl`](vrl/) | Command-line client for [Vulnerability Research Labs](https://vrl.quantrosecurity.ai): submit a CVE, watch it move through the pipeline live, and read the result. Run it with `./vrl/bin/vrl`. |
